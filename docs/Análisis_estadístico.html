4.2 Objetivo 1: supuestos de normalidad y homogeneidad

Ahora separaremos los valores de tasa de mortalidad según el nivel de pobreza.

y_alta <- df %>% filter(nivel_pobreza == "Pobreza alta") %>% pull(target_deathrate)
y_baja <- df %>% filter(nivel_pobreza == "Pobreza baja") %>% pull(target_deathrate)

Una vez dividido, observamos que se divide en 1525 condados que clasifican como Pobreza alta y 1522 condados como Pobreza baja. Ahora con Shapiro-Wilk vamos a comprobar su normalidad

Sin embargo, dado el gran tamaño de los datos en ambos grupos (n>1500), podemos seguir aplicando el t-test de manera robusta, apoyándonos en el Teorema de Límite Central.

4.3 Objetivo 2: comparación de la tasa de mortalidad entre niveles de pobreza

En este sentido, ahora queremos comprobar si existe una diferencia significativa entre la tasa de mortalidad promedio:

Ho: μ(alta) = μ(baja) vs Ha: μ(alta) != μ(baja)

media_alta <- mean(y_alta)
media_baja <- mean(y_baja)

diferencia <- media_alta - media_baja
SE_welch <- sqrt(var_alta/n1 + var_baja/n2)

t_manual <- diferencia / SE_welch
gl_welch <- (var_alta/n1 + var_baja/n2)^2 /

4.5 Objetivo 4. Contrastar el efecto del balance de cobertura médica

Paso 1: Categorización de coverage_balance en 3 grupos (terciles) Se optó por dividir coverage_balance en terciles (en lugar de utilizar puntos de corte fijos o arbitrarios) porque este método garantiza que cada grupo contenga aproximadamente el mismo número de observaciones (33.3% de los datos cada uno), lo cual es preferible para un análisis de varianza, ya que grupos con tamaños muestrales muy desbalanceados pueden afectar la potencia estadística de la prueba y la validez del supuesto de homogeneidad de varianzas. Además, al basarse en los percentiles reales de la distribución de la variable (y no en umbrales predefinidos sin fundamento estadístico, como 0 o 30), los terciles reflejan de forma más fiel la estructura y variabilidad observada en los datos, evitando que la elección subjetiva de los puntos de corte introduzca sesgos en la comparación de grupos.

terciles <- quantile(df$coverage_balance, probs = c(1/3, 2/3))

df <- df %>% 
  mutate(categoria_cobertura = case_when(
    coverage_balance <= terciles[1] ~ "Predominio público",
    coverage_balance <= terciles[2] ~ "Balance intermedio",

4.7.1 Variables dummy

Una variable dummy toma solo los valores 0 o 1 e indica si una observación pertenece o no a una categoría. Una variable con \(k\) categorías se representa con \(k - 1\) dummies; la categoría que queda sin dummy es la referencia. Si se incluyeran las \(k\) dummies junto con el intercepto, la suma de todas ellas sería igual a la columna de unos y el modelo no se podría estimar (trampa de las variables dummy).

Como binnedinc tiene 10 niveles, se crean 9 dummies. Se toma como referencia el decil 1 (el ingreso más bajo, de 22 640 a 34 218 dólares), de modo que cada coeficiente mide cuánto cambia la mortalidad en un rango de ingreso más alto respecto a los condados más pobres:

\[D_{ji} = \begin{cases} 1 & \text{si el condado } i \text{ pertenece al decil } j \\ 0 & \text{en otro caso} \end{cases} \qquad j = 2, \dots, 10\]

4.7.5 Modelo 2: binnedinc junto con las demás variables

El modelo 1 no controla por otras variables, así que parte de la diferencia entre deciles puede deberse a la educación, la cobertura médica o la incidencia de cáncer, que también cambian con el ingreso. Para aislar el efecto del ingreso, se parte del modelo de 10 variables del objetivo 6 (Capítulo 5).

binnedinc es una versión agrupada de medincome, que ya está en ese modelo como inv(medincome). Incluir ambas sería medir el ingreso dos veces, así que en el modelo 2 se reemplaza el ingreso continuo por el categórico: se conservan las otras nueve variables (con sus mismas transformaciones) y se agregan las nueve dummies de binnedinc.

\[Y_i = \beta_0 + \sum_{k=1}^{9} \gamma_k\, g_k(X_{ki}) + \sum_{j=2}^{10} \beta_j D_{ji} + \varepsilon_i\]

resumen_modelo <- function(m) {
  s <- summary(m)
  n_obs <- nobs(m)
  p <- length(coef(m))
  sse <- sum(residuals(m)^2)
  tibble(Parametros = p,
         R2 = s$r.squared,
         R2_ajustado = s$adj.r.squared,
         AIC = n_obs * log(sse / n_obs) + 2 * p,

}

4.7.7 Conclusión del objetivo 7

  • binnedinc, la única variable categórica, se incorporó a la regresión con 9 variables dummy, tomando como referencia el decil de ingreso más bajo.
  • Sola, explica el 20.4 % de la variabilidad de la mortalidad: los condados del decil más alto tienen en promedio 43.6 muertes menos por cada 100 000 habitantes que los del decil más bajo, y todas las diferencias frente al decil 1 son significativas.
  • Al controlar por las demás variables, el efecto del ingreso se reduce a unas 5 a 13 muertes menos, pero sigue siendo significativo en conjunto (F parcial = 5.46, p < 0.05; también con errores robustos).
  • El efecto del ingreso no es lineal: crece hasta el decil 7 y luego se estabiliza. Esto sugiere que la reducción de mortalidad asociada al ingreso se concentra en pasar de ingresos bajos a ingresos medios.
  • Para describir el efecto del ingreso conviene el modelo categórico, porque muestra la diferencia de cada nivel. Para un modelo más sencillo, el BIC favorece el modelo de 10 variables con el ingreso continuo, que sigue siendo el modelo principal del estudio.
