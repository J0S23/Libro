plot_univariado <- function(df, var) {
  #Boxplot
  p_box <- df %>% 
    ggplot(aes(x = "", y = .data[[var]])) +
    geom_boxplot(fill = "#8ecae6", color = "#023047", 
                 outlier.color = "#e63946") +
    stat_summary(fun = mean, geom = 'point', shape = 20, size = 3, color = '#023047') +
    labs(title = paste("Diagrama de cajas y bigotes"), x = NULL, y = var) +
    theme_bw()
  #Histograma de polígonos
  p_hist <- df %>% 
    ggplot(aes(x = .data[[var]]))+
    geom_histogram(aes(y = after_stat(count)), fill = "#8ecae6", color = "white", bins = 30) +
    geom_freqpoly(color = "#023047", linewidth = 1, alpha = 0.8, bins = 30) +
    labs(title = paste("Histograma de polígonos"), x = var, y = "Frecuencia") +
    theme_bw()
  #combinar los dos plots
  p_hist + p_box
}

1.3 Análisis exploratorio bivariado

plot_dispersión_respuesta <- function(df, var, var_label) {
  df %>%
    ggplot(aes(x = .data[[var]], y = median_house_value)) +
    geom_point(alpha = 0.4, color = "#1E90FF") +
    geom_smooth(method = "lm", formula = y ~ x, se = FALSE, color = "red") +
    labs(
      x = var_label,
      y = "Valor medio de la vivienda (USD)"
    ) +
    theme_bw() +
    facet_grid(. ~ paste("Dispersión entre", var_label, "y el valor medio de las viviendas"))
}
plot_dispersión_respuesta(df, "median_income", "ingreso medio")

Los puntos muestran una tendencia ascendente clara: a mayor ingreso medio, mayor valor medio de la vivienda. La mayoría de las observaciones se concentra entre ingresos de 2 a 6, con valores por debajo de 400.000 USD.

La dispersión aumenta con el ingreso, es decir, en zonas de mayores ingresos hay más variabilidad en los precios. También se nota una acumulación de puntos en 500,000 USD, el límite superior del dataset, lo que sugiere censura en la variable objetivo.

Seguidamente, crearemos una función para analizar cada pareja de variables características numéricas

graf_dispersion <- function(var_x, var_y) {
  df %>% 
    ggplot(aes(x = .data[[var_x]], y = .data[[var_y]])) +
    geom_point(alpha = 0.4, color = 'darkblue') +
    geom_smooth(method = "lm", formula = y ~ x, se = FALSE, color = "red") +
    theme_bw()
}

1.4 Ingeniería de características

Con base en la matriz de correlación, identificamos que total_rooms, total_bedrooms, population y households están altamente correlacionadas entre sí, ya que todas escalan según el tamaño del bloque censal. Para reducir esta redundancia, eliminamos estas 4 variables originales y las combinamos en 4 nuevas variables; habitaciones_por_hogar, dormitorios_por_habitacion, poblacion_por_hogar e ingreso_por_persona.
