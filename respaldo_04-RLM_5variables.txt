# Regresión lineal múltiple {#rlm}

Hasta aquí se ha evaluado la asociación de cada variable socioeconómica con `target_deathrate` de forma individual. En esta sección se estudia su efecto conjunto mediante un modelo de regresión lineal múltiple (RLM), con `target_deathrate` como variable respuesta y como regresoras las variables que sustentan la evidencia bivariada de los objetivos 1 a 5: `povertypercent`, `medincome`, `pctbachdeg25_over`, `coverage_balance` y `pctunemployed16_over`.

El modelo poblacional es

$$Y_i = \beta_0 + \beta_1 X_{1i} + \dots + \beta_k X_{ki} + \varepsilon_i, \qquad \varepsilon_i \overset{iid}{\sim} N(0, \sigma^2),$$

y se evalúa mediante el coeficiente de determinación $R^2$, el $R^2$ ajustado, el análisis de los residuos y los criterios de selección (AIC, BIC y $C_p$ de Mallows).

```{r librerias-rlm, message=FALSE, warning=FALSE}
library(lmtest)     # bptest, dwtest, coeftest
library(sandwich)   # vcovHC (errores estándar robustos)
```

Se define la variable respuesta y se verifica que las cinco regresoras no tengan datos faltantes tras la imputación.

```{r datos-rlm}
vars <- c("povertypercent", "medincome", "pctbachdeg25_over",
          "coverage_balance", "pctunemployed16_over")

df_rlm <- df %>% select(target_deathrate, all_of(vars))

n <- nrow(df_rlm)
colSums(is.na(df_rlm))
n
```

## Modelo lineal inicial

Primero se ajusta el modelo con las cinco variables sin transformar.

```{r rlm-lineal}
mod_lineal <- lm(target_deathrate ~ povertypercent + medincome +
                   pctbachdeg25_over + coverage_balance +
                   pctunemployed16_over, data = df_rlm)
summary(mod_lineal)
```

El modelo lineal es globalmente significativo (F = 251.2 con 5 y 3041 grados de libertad, p < 0.05): al menos un coeficiente es distinto de cero. Sin embargo, explica solo $R^2 = 0.292$ de la variabilidad de `target_deathrate` ($R^2$ ajustado = 0.291) y el error estándar residual es de 23.37 muertes por cada 100 000 habitantes. Además, `medincome` no resulta significativa de forma lineal (p ≈ 0.46), a pesar de la asociación observada en el análisis bivariado. Esto sugiere que la relación con el ingreso no es lineal.

Se revisa la multicolinealidad mediante el factor de inflación de la varianza (VIF). Valores superiores a 5 se consideran problemáticos.

```{r vif-lineal}
vif(mod_lineal)
```

Todos los VIF son inferiores a 5 (máximo 4.31, en `medincome` y `coverage_balance`), por lo que no hay multicolinealidad severa, aunque `povertypercent`, `medincome` y `coverage_balance` comparten información.

## Transformaciones de las variables

Siguiendo las transformaciones de la regresión simple (logarítmica, raíz cuadrada, inversa y cuadrática), se evalúan todas las combinaciones posibles de transformaciones para las cinco regresoras (5⁵ = 3125 modelos), manteniendo `target_deathrate` sin transformar. La variable `coverage_balance` toma valores negativos, por lo que antes de aplicar logaritmo, raíz o inverso se desplaza a $\text{coverage\_balance} - \min(\text{coverage\_balance}) + 1 \geq 1$. El criterio de comparación es el $R^2$ ajustado.

```{r grid-transformaciones}
y <- df_rlm$target_deathrate
sst <- sum((y - mean(y))^2)
cov_min <- min(df_rlm$coverage_balance)

transformar <- function(v, t) {
  x <- df_rlm[[v]]
  if (v == "coverage_balance" && t %in% c("ln", "sqrt", "inv")) x <- x - cov_min + 1
  switch(t, x = x, ln = log(x), sqrt = sqrt(x), inv = 1 / x, sq = x^2)
}

tipos <- c("x", "ln", "sqrt", "inv", "sq")
Tm <- lapply(vars, function(v) lapply(setNames(tipos, tipos), function(t) transformar(v, t)))

grid <- expand.grid(rep(list(tipos), length(vars)), stringsAsFactors = FALSE)
names(grid) <- vars

r2aj <- vapply(seq_len(nrow(grid)), function(i) {
  X <- cbind(1, sapply(seq_along(vars), function(j) Tm[[j]][[grid[i, j]]]))
  sse <- sum(lm.fit(X, y)$residuals^2)
  r2 <- 1 - sse / sst
  1 - (1 - r2) * (n - 1) / (n - ncol(X))
}, numeric(1))

grid$R2_ajustado <- round(r2aj, 4)
grid %>% arrange(desc(R2_ajustado)) %>% head(5)
```

La mejor combinación es $\text{povertypercent}^2$, $1/\text{medincome}$, $\sqrt{\text{pctbachdeg25\_over}}$, $\ln(\text{coverage\_balance}')$ y $\ln(\text{pctunemployed16\_over})$, con $R^2$ ajustado = 0.3051. La mejora respecto al modelo lineal (0.2911) es de apenas 0.014: el techo de $R^2$ con estas cinco variables ronda 0.31, sin importar la transformación aplicada.

Se construye el modelo con esta combinación.

```{r rlm-transformado}
df_rlm <- df_rlm %>%
  mutate(pov2     = povertypercent^2,
         inv_inc  = 1 / medincome,
         raiz_bach = sqrt(pctbachdeg25_over),
         ln_cov   = log(coverage_balance - cov_min + 1),
         ln_unemp = log(pctunemployed16_over))

mod_final <- lm(target_deathrate ~ pov2 + inv_inc + raiz_bach +
                  ln_cov + ln_unemp, data = df_rlm)
summary(mod_final)
```

## $R^2$ y $R^2$ ajustado

```{r comparacion-r2}
sse_p <- function(m) sum(residuals(m)^2)

comparacion <- data.frame(
  Modelo = c("Lineal", "Transformado"),
  R2 = c(summary(mod_lineal)$r.squared, summary(mod_final)$r.squared),
  R2_ajustado = c(summary(mod_lineal)$adj.r.squared, summary(mod_final)$adj.r.squared),
  Error_residual = c(sigma(mod_lineal), sigma(mod_final)),
  AIC = c(n * log(sse_p(mod_lineal) / n) + 2 * 6,
          n * log(sse_p(mod_final) / n) + 2 * 6),
  BIC = c(n * log(sse_p(mod_lineal) / n) + 6 * log(n),
          n * log(sse_p(mod_final) / n) + 6 * log(n))
)
comparacion %>% mutate(across(where(is.numeric), ~ round(., 4)))
```

(AIC y BIC se calculan como $n\ln(SSE/n) + 2p$ y $n\ln(SSE/n) + p\ln n$, la misma forma que usa `step()`.)

El modelo transformado explica el 30.6 % de la variabilidad de `target_deathrate` ($R^2$ = 0.306; $R^2$ ajustado = 0.305), frente al 29.2 % del lineal. Además, presenta menor error residual (23.13 frente a 23.37) y menores AIC y BIC, por lo que se prefiere el modelo transformado. Su prueba F global es altamente significativa (F = 268.5, p < 0.05).

El restante ≈ 69.5 % de la variabilidad no es explicado por estas variables socioeconómicas: el modelo describe una asociación, pero no es adecuado para predecir la tasa de mortalidad de un condado en particular.

La transformación $1/\text{medincome}$ es significativa (t = 5.48), mientras que `medincome` lineal no lo era (t = −0.74). Esto confirma que el efecto del ingreso es no lineal: el aumento del ingreso reduce la mortalidad de forma marcada en los ingresos bajos y mucho menos en los altos.

## Multicolinealidad

```{r vif-final}
vif(mod_final)
```

Los VIF son 3.99, 5.44, 2.03, 3.73 y 1.51. Solo $1/\text{medincome}$ supera ligeramente el umbral de 5, lo que indica una colinealidad moderada con `povertypercent` (ambas miden condiciones económicas del condado). No se considera severa y se conserva la variable, teniendo presente que su error estándar puede estar algo inflado.

## Análisis de los errores

Se verifican los supuestos del modelo sobre los residuos: normalidad, varianza constante, independencia y presencia de observaciones atípicas o influyentes.

```{r graficos-residuos, fig.width=9, fig.height=4}
par(mfrow = c(1, 2))
plot(mod_final, which = 1)   # residuos vs ajustados
plot(mod_final, which = 2)   # Q-Q normal
par(mfrow = c(1, 1))
```

El gráfico de residuos contra valores ajustados muestra una dispersión que cambia con el nivel ajustado (varianza no constante), y el Q-Q plot se aparta de la recta en ambos extremos (colas más pesadas que la normal).

**Normalidad.** Ho: los errores siguen una distribución normal.

```{r normalidad-residuos}
res <- residuals(mod_final)
shapiro.test(res)
c(asimetria = skewness(res), curtosis = kurtosis(res))
```

Se rechaza Ho (W = 0.976, p < 0.05). Los residuos son prácticamente simétricos (asimetría = −0.05), pero con colas pesadas (curtosis = 5.56 > 3, distribución leptocúrtica). Dado que n = 3047, el teorema del límite central hace que las pruebas t y F sigan siendo aproximadamente válidas ante este incumplimiento.

**Homocedasticidad.** Ho: la varianza de los errores es constante.

```{r bp-test}
bptest(mod_final)
```

Se rechaza Ho (BP = 174.2, gl = 5, p < 0.05): hay heterocedasticidad. Los errores estándar clásicos no son confiables, por lo que más adelante se emplean errores estándar robustos.

**Independencia.** Ho: no hay autocorrelación de primer orden en los errores.

```{r dw-test}
dwtest(mod_final)
```

El estadístico de Durbin-Watson es 1.635 (< 2) y se rechaza Ho: existe una autocorrelación positiva leve entre residuos consecutivos. Es esperable en datos de condados, donde los condados de un mismo estado o región comparten características no observadas.

**Observaciones atípicas e influyentes.**

```{r cook-atipicos, fig.width=7, fig.height=4}
plot(mod_final, which = 4)   # distancia de Cook

cook <- cooks.distance(mod_final)
c(max_cook = max(cook), n_cook_mayor_4n = sum(cook > 4 / n), n_cook_mayor_1 = sum(cook > 1))

rstud <- rstudent(mod_final)
sum(abs(rstud) > 3)

outlierTest(mod_final)
```

La distancia de Cook máxima es 0.054, muy inferior a 1: ninguna observación es influyente. Solo 36 observaciones (1.2 %) tienen residuos studentizados mayores a 3 en valor absoluto, por lo que se conservan en el modelo. La prueba de Bonferroni (`outlierTest`) marca 5 de ellas como atípicas (filas 1490, 1221, 1942, 1366 y 1059, con p ajustado < 0.05), pero ninguna es influyente, de modo que no alteran las conclusiones.

## Errores estándar robustos

Dado el incumplimiento de la homocedasticidad, los contrastes de significancia individual se recalculan con errores estándar robustos (HC3).

```{r hc3}
coeftest(mod_final, vcov. = vcovHC(mod_final, type = "HC3"))
```

Con errores robustos, `inv_inc`, `raiz_bach`, `ln_cov` y `ln_unemp` siguen siendo significativos (|t| entre 4.1 y 13.3). En cambio, `pov2` pasa de t = 2.40 a t = 1.71 (p ≈ 0.09) y deja de ser significativa al 5 %: su aporte depende de que se acepte la varianza constante, supuesto que no se cumple.

Los intervalos de confianza al 95 % con estos errores son

```{r ic-hc3}
coefci(mod_final, vcov. = vcovHC(mod_final, type = "HC3"), level = 0.95)
```

## Selección del mejor modelo

Se comparan todos los subconjuntos posibles de las cinco regresoras transformadas (31 modelos) según $R^2$ ajustado, AIC, BIC y el estadístico $C_p$ de Mallows, calculado respecto al modelo completo como $C_p = SSE_p / \hat{\sigma}^2_{completo} - (n - 2p)$, donde $p$ es el número de parámetros (incluyendo el intercepto). Un modelo sin sesgo tiene $C_p \approx p$.

```{r todos-subconjuntos}
regs <- c("pov2", "inv_inc", "raiz_bach", "ln_cov", "ln_unemp")
s2_full <- summary(mod_final)$sigma^2

subs <- do.call(rbind, lapply(1:5, function(q) {
  do.call(rbind, lapply(combn(regs, q, simplify = FALSE), function(v) {
    m <- lm(reformulate(v, "target_deathrate"), data = df_rlm)
    p <- q + 1
    sse <- sum(residuals(m)^2)
    data.frame(variables = paste(v, collapse = " + "), q = q,
               R2_aj = summary(m)$adj.r.squared,
               AIC = n * log(sse / n) + 2 * p,
               BIC = n * log(sse / n) + p * log(n),
               Cp = sse / s2_full - (n - 2 * p))
  }))
}))

# Mejor modelo de cada tamaño según R2 ajustado
subs %>%
  group_by(q) %>%
  slice_max(R2_aj, n = 1) %>%
  ungroup() %>%
  mutate(across(c(R2_aj, AIC, BIC, Cp), ~ round(., 3)))
```

El mejor modelo de cada tamaño agrega, en orden, `raiz_bach`, `ln_unemp`, `inv_inc`, `ln_cov` y `pov2`. Los resultados son:

| Variables | $R^2$ ajustado | AIC | BIC | $C_p$ |
|---|---|---|---|---|
| 1 (`raiz_bach`) | 0.2446 | 19399.6 | 19411.7 | 267.3 |
| 2 (+ `ln_unemp`) | 0.2879 | 19220.5 | 19238.6 | 78.3 |
| 3 (+ `inv_inc`) | 0.2993 | 19172.6 | 19196.7 | 29.6 |
| 4 (+ `ln_cov`) | 0.3040 | 19152.8 | **19182.9** | 9.8 |
| 5 (+ `pov2`) | **0.3051** | **19149.1** | 19185.2 | 6.0 |

Los criterios de $R^2$ ajustado, AIC y $C_p$ seleccionan el modelo completo de cinco variables, mientras que el BIC, que penaliza más la complejidad, prefiere el de cuatro (sin `pov2`). La diferencia de BIC entre ambos es de 2.3, es decir, ambos modelos son prácticamente equivalentes. Se verifica con selección por pasos hacia atrás:

```{r step-aic}
step(mod_final, direction = "backward", trace = 0)$call            # criterio AIC
step(mod_final, direction = "backward", trace = 0, k = log(n))$call # criterio BIC
```

**Modelo seleccionado.** Se retiene el modelo de cinco variables transformadas, ya que (i) maximiza el $R^2$ ajustado y minimiza el AIC y $C_p$, y (ii) mantiene la pobreza, variable central de los objetivos 1 y 2. Se aclara que la significancia de `pov2` no es robusta ante la heterocedasticidad.

$$\widehat{\text{target\_deathrate}} = 125.38 + 0.00765\,\text{pov}^2 + 1\,031\,150\,\frac{1}{\text{medincome}} - 13.51\sqrt{\text{bach}} + 13.18\ln(\text{cov}') + 11.10\ln(\text{unemp})$$

## Conclusión del capítulo

- Las variables socioeconómicas explican en conjunto cerca del 30 % de la variabilidad de la tasa de mortalidad por cáncer ($R^2$ ajustado = 0.305), y el modelo es globalmente significativo (p < 0.05).
- La mortalidad aumenta con el desempleo y con la pobreza, y disminuye con el nivel educativo y con el ingreso (de forma no lineal). El coeficiente positivo de `ln_cov` es contrario a lo esperado en una lectura marginal; debe interpretarse condicionado a las demás variables, con las que comparte información (VIF cercano a 4).
- Los residuos no cumplen normalidad, homocedasticidad ni independencia estrictas. Por el tamaño muestral (n = 3047) la inferencia sigue siendo aproximadamente válida, y se corrige la heterocedasticidad con errores estándar HC3.
- No hay observaciones influyentes (distancia de Cook máxima = 0.054).
- Por su bajo $R^2$ y la heterocedasticidad, el modelo sirve para describir la asociación conjunta de los factores socioeconómicos con la mortalidad, y no para predecir la tasa de un condado individual.
